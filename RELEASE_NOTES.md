# Travel OS v0.4.11

Weather re-planning workflow.

Travel OS now has a dedicated weather workflow. It records forecast provenance and timing, checks whether the forecast covers the travel date, freezes completed history, preserves confirmed bookings and changes only the affected future itinerary after Owner approval.

When the trip lies outside the useful forecast window, the Skill keeps the current plan and creates a dated recheck task instead of inventing weather. The release includes a directly installable `Travel-OS-Skill-v0.4.11.zip`, the full repository archive and checksums for both. The package passes 32 contract tests.
