# Security and privacy

Travel archives can reveal dates, locations, companions, bookings and health or mobility needs. Treat every workbook as private.

## Report a vulnerability privately

Use GitHub's [private vulnerability reporting](https://github.com/tygshy97-AshAyuan/travel-os/security/advisories/new) for credential exposure, unsafe file handling, privacy leaks or instructions that could overwrite or disclose a user's archive.

Do not attach a real travel archive. Replace names, dates, addresses, booking references, contact details, identity documents and credentials with fictional values.

For ordinary product bugs that contain no sensitive data, use the public Bug Report form.

## Supported versions

Security and privacy fixes target the latest GitHub Early Access release.
