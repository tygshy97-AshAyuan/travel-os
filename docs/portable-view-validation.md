## 首条验收路径：上海 → 杭州三天

1. **日期未定的新旅行**：输入“从上海去杭州三天，想轻松一些，日期未定”。期望先给第 1 / 2 / 3 天的可讨论骨架，只问影响路线的问题；不得编造日期、人数或正式 Active Version。
2. **形成正式计划**：提供日期、同行人数、负责人、固定订单与实际偏好；明确接受方案后创建并校验档案，再生成 HTML。该步尚未拿到真实信息，不标记通过。
3. **查看手机页**：目前可用 `artifacts/china-domestic.html` 检查功能。2030 年日期、安排、费用及订单均为虚构，与真实旅行无关。
4. **改期**：演示页显示同一散步项目由 14:00–16:00 改为 15:00–17:00；只有当前版本的安排进入每日页，旧版本出现在差异区。自动测试已覆盖；完整对话中提案、确认、写回、重新导出还需客户端行为验收。
5. **跨会话**：新会话提供最新 XLSX，应恢复同一版本；单独 HTML 不能替代完整档案。待客户端测试。

## 待完成的兼容性验证

- 内置浏览器拒绝打开 `file://` 本地文件，理由为 URL 安全策略只允许 HTTP/HTTPS；没有换协议或绕过该策略继续该项操作。因此本地文件复制、日期筛选、打印对话框与生成 PDF 尚无真实浏览器操作证据。
- iPhone Safari / Android Chrome 打开下载文件、所有日期打印、剪贴板失败时手动复制，需要真机验收；微信内置预览不作已支持承诺。
- ChatGPT 的文件能力随入口而异；当前没有证明所有 ChatGPT 界面可安装或自动发现 Skill。应在实际使用入口测试附件交付与再次上传恢复。
- 高德/Google 链接仅验证构造与编码；目的地网络可达性、候选地点准确性和导航效果仍需现场/实际服务验收。
- 未发布安装包、未改全局安装、未创建账户、未部署服务、未增加遥测。下载量不能据此当作用户量。
