# 五分钟上手

1. 打开 Excel 模板，在 `Travel Overview` 填写目的地、日期、旅行人数和负责人，并在 `Members` 建立对应成员。
2. 保持 Active Version 为 `v0.1.0`，在 `Daily Plan` 中填写同版本行程；已确认订单写入 `Bookings`。
3. 上传表格并要求 AI：`先告诉我 Active Version 和缺失信息，不要直接改表。`
4. 发起一次修改，检查 AI 是否先给出提案。
5. 确认后检查 Active Version 是否更新，旧版本是否保留在 `Change Log`。

公开反馈时不要上传原旅行档案。用虚构地点和日期复现问题即可。
