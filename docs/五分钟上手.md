# 五分钟上手

1. 复制空白 Excel 模板，在 `Travel Overview` 填写目的地、日期、旅行人数、负责人和 `Draft` 状态，并在 `Members` 建立对应成员。此时 Active Version 保持为空。
2. 把初步行程写入 `Daily Plan`，已确认订单写入 `Bookings`。需要填写示范时查看 `TravelOS-Example.xlsx`。
3. 上传表格并要求 AI：`先告诉我 Active Version 和缺失信息，不要直接改表。`
4. 发起一次修改，检查 AI 是否先给出提案。
5. 初次确认后检查 Active Version 是否成为 `v0.1.0`，后续修改时检查旧版本是否保留在 `Change Log`。

公开反馈时不要上传原旅行档案。用虚构地点和日期复现问题即可。
